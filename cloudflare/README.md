# Development realtime Worker

`src/index.ts` is the authenticated router; `UserRealtime` owns one dataset/user compacted SQLite room projection. MongoDB authorizes writes and stores messages and current per-user room state. Cloudflare assigns delta cursors and retains one latest room-list summary per room for 48 hours. Message history stays in MongoDB; there is no Mongo event journal or Redis. First use, expiry, epoch reset or an excessive gap falls back to the newest 20-room HTTP snapshot.

From the repository root, build the shared contracts before installing this component:

```sh
npm --prefix shared ci
npm --prefix shared run build
npm --prefix cloudflare ci
npm --prefix cloudflare run typecheck
npm --prefix cloudflare test
npm --prefix cloudflare run build
```

The build command is a Wrangler **dry run**, with no deployment. Runtime types are generated by `typecheck` and ignored in Git. Dependencies and the lockfile are pinned. Wrangler 4.151.0 validates the declarative SQLite class `exports` flow; the pinned workerd runtime supports compatibility date `2026-10-12` and rejects `2026-10-15` as a future date.

Use the root setup helper to map the development configuration from `nestjs/.env`. It creates ignored `wrangler.local.jsonc` and `.dev.vars.development`; only the upgrade-ticket and integration secrets belong in the runtime. Start the isolated local Worker using:

```sh
npm --prefix cloudflare run dev:local -- --config wrangler.local.jsonc
```

Canonical routes, header/auth requirements, socket frames and retention are specified in [CONFIGURATION.md](CONFIGURATION.md), [WEBSOCKET_PROTOCOL.md](WEBSOCKET_PROTOCOL.md) and [OFFLINE_SYNC.md](OFFLINE_SYNC.md). Internal requests use `Authorization: Bearer …` and `X-Dataset-Id`. Presence query returns `{ datasetId, items }`; stream inspection and append responses also identify the dataset and user.

The tests run inside local workerd with real Durable Object SQLite and hibernatable sockets. They cover authentication/identity failures; source-revision idempotency/conflicts; room compaction; payload expiry and retained source watermarks; schema migration/re-entry; independent device ACKs; sparse replay coverage; frame count/byte limits; frozen in-flight retransmission after a newer update and actual **local** object eviction; aggregated presence/snapshot recovery; and alarm deadlines. Fixtures rotate isolated dataset IDs without deleting stored datasets. Expected failure injection can emit workerd RPC diagnostics.

Passing these tests proves local runtime behavior. It does not prove a real Cloudflare deployment, real-cloud hibernation, or mobile-device behavior. Those gates require separately recorded evidence. No management credential, reset route, production target, or deployment command is included in this component's run scripts.

Schema4 adds a transactionally maintained retained-room counter and indexed, deadline-driven expiry checks. Idle presence alarms avoid repeating the room delta pump. The wire protocol and 48-hour retention are unchanged. See [SQL_READ_REPORT.md](SQL_READ_REPORT.md) for local before/after measurements and [CLOUD_OPTIMIZATION_REPORT.md](CLOUD_OPTIMIZATION_REPORT.md) for the15October2026 deployment, real-cloud replay/retention checks and live SQL usage.
